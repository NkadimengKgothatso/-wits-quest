# Enhanced Battle System (Proposal)

!!! note "Status: proposal"
    This is an idea the team is weighing up, not something that's built yet. Nothing here changes the current battle rules.

The short version: keep the card battle exactly as the brief describes it, but show it as two avatars fighting turn by turn. Your deck becomes the avatar's stats and abilities, you still choose every move, and the server still decides every result.

The page below is interactive. You can build a small deck, play a demo battle against the CPU, and see how each part lines up with the original requirements.

[Open the interactive page in a new tab](files/enhanced-battle-system.html){ .md-button .md-button--primary target="_blank" }

## What still needs a decision

- What the avatar should look like (student, mascot, or a figure per category).
- How rarity is balanced. The page uses averaged stats and ability cooldowns as a starting point, but the numbers need playtesting.
- Whether we ship it for CPU battles first and bring it to PvP later.
