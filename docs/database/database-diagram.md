# Database Diagram

The whole Wits Quest database in one picture: all 27 tables and their columns, grouped and coloured by area. Each arrow goes from a link column (**FK**) to the table it points to, and **PK** marks each table's primary key.

Click the picture to open it full size and zoom in.

[![The full Wits Quest database: 27 tables in 8 groups](images/database-diagram.svg)](images/database-diagram.svg)

[Download as PNG](images/database-diagram.png)

| Colour | Area |
| :--- | :--- |
| Blue | Players and cards |
| Green | Events and trivia |
| Red | Battles |
| Orange | Trading |
| Purple | Quest trails and territory |
| Teal | Ranked seasons |
| Grey | Anti-cheat |
| Pink | Achievements |

What each column holds is on [Database Schema](database-schema.md). Smaller diagrams of the same links, split by area, are on the [ERD](../uml/04_erd_database_schema.md) page.
