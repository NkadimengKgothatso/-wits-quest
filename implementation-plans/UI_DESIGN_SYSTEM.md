# Wits Quest - Anime Realism Design System Reference

## Color Palette Tokens

- **Midnight Navy (`#1d3156`)**: Primary app background, deep twilight containers, dark mode navigation.
- **Steel Slate (`#496894`)**: Glassmorphic panels, inventory card frames, secondary action buttons.
- **Periwinkle Ice (`#a4b5d1`)**: Subtitles, soft borders, inactive navigation badges.
- **Sky Blue (`#b0cbe6`)**: Active map pins, in-reach radius highlights, interactive controls.
- **Sunset Peach (`#fed6ce`)**: Energy glow highlights, primary hero action buttons, legendary card borders.

## Aesthetic Guidelines

1. **Glassmorphism**: Use `backdrop-filter: blur(12px)` with semi-transparent navy backgrounds.
2. **Glowing Highlights**: Primary buttons and active event markers feature soft radial glows (`box-shadow: 0 0 20px rgba(254, 214, 206, 0.45)`).
3. **Typography**: Google Fonts (_Outfit_ / _Plus Jakarta Sans_) with high contrast white text (`#ffffff`) for readability over dark backgrounds.
