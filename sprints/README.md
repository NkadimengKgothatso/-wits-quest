# Sprints

Wits Quest is developed in two-week sprints. This section contains the specifications, implementation guides, and handover documentation for each sprint.

---

## Sprint 1 — Core Loop & Foundation

The first sprint focused on building the core game loop: campus map, geofenced trivia, card collection, CPU battles, and the authoring console.

## Sprint 2 — PvP, Progression & Infrastructure

Sprint 2 expanded the game with PvP (async and live), progression systems (streaks, leaderboards), battle hub, card forge, territory control, and significant infrastructure work (lints, CI/CD, repo separation, documentation).

---

## Sprint 3 — Milestone 3: Trustworthy, Tested & Documented (15 → 29 Sep)

Sprint 3 finishes the Basic and Intermediate tiers and targets every line of the Milestone 3 rubric: server-side location checks, server-enforced CPU battles, spectating, anti-cheat, QR check-in, trading, quest trails, admin-created achievements, analytics, streaks, mobile accessibility, content review and campaigns, real campus content, an audited and versioned API, CI coverage gates, and two rounds of user testing. Ranked matchmaking, territory, trust responses and automatic event placement carry into the final submission on 11 Oct.
